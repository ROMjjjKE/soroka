# ИП Сорока — монолит, кладка, кровля. Лида

Шесть страниц: index, uslugi, raboty, proizvodstvo, kontakty, politika.
Интерактив: разрез конструкции (3 узла × 5 слоёв, клик по слою или по схеме), фильтр объектов, заявка в WhatsApp.
Критический CSS встроен в <style> ДО ссылки на assets/css/style.v1.css.

## Перед запуском
1. УНП в подвал и политику.
2. Реальные фото объектов вместо сгенерированных.
3. Подтвердить формулировки: выезд на объект, договор, предоплата на материалы, гарантия по кладке.
4. Часы работы и радиус выезда.
